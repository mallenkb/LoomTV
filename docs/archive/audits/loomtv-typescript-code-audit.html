Issues to address next
1

Two major renderers and the mobile style module remain large.

ArchitectureMedium-priority issue

Evidence. Mobile playback controls and progress now live in useMobilePlayerSession.ts, brightness and volume gestures live in useMobilePlayerGestures.ts, and desktop seek behavior lives in usePlayerScrubbing.ts. This reduced App.tsx to 6,752 lines and VideoPlayer.tsx to 3,622 lines without generic controller wrappers.

Problem. Connection and profile orchestration still share the mobile renderer, while desktop transport, tracks, subtitles, and overlays remain coupled.

Why it matters. The extracted hooks have explicit typed contracts and narrow effects, but distant state transitions remain in the parent modules.

Recommendation. Continue the same state-owner pattern for mobile connection/profile state and desktop transport/tracks. Move feature styles only with their owning component.
2

SQLite result families now parse at repository boundaries.

Type disciplineWorking well

Evidence. Playback, artwork, thumbnail, plugin, profile, and segment repositories now validate SQLite rows with named Zod schemas. Production assertions fell from 402 to 347, with unavoidable platform values kept inside native adapter modules.

Why it works. Database values enter application code as parsed results rather than claimed shapes, so schema drift fails locally and carries repository context.

What to preserve. Add one named schema for each new row family and keep native interop casts inside the platform adapter that owns them.
Needs verification

Release verification is broad; one connected mobile path remains.

VerificationNeeds verification

Evidence. The full workspace suite passes. Lint, typecheck, production dependency policy, desktop production build, iOS and Android production bundles, and a native iOS simulator build all pass. Working well to preserve
4

The repository's static TypeScript gates are green.

Quality gateWorking well

Evidence. The TVmaze platform value is narrowed to a non-null local before its fields are read. pnpm typecheck and pnpm lint both complete successfully across the workspace. Production TypeScript contains zero explicit any keywords, zero non-null assertions, and zero exhaustive-dependency suppressions.

Why it works. Ordinary narrowing and inferred values carry the implementation. Exceptions remain visible instead of disappearing into broad casts or framework-shaped wrappers.

What to preserve. Keep strictness and hook rules at error level in every package, and require both commands before release.

5

Canonical schemas now own cross-platform media contracts.

Domain modelingWorking well

Evidence. packages/lan-protocol/src/schemas.ts exports inferred types for ratings, providers, platforms, tracks, local details, subtitles, episodes, cast, and media items. Mobile derives its required identity and optional metadata view from LanMediaItem. Named parsers validate database rows and IPC argument tuples at their boundaries.

Why it works. Runtime validation and compile-time types originate from one schema, then application state narrows that contract instead of copying it.

What to preserve. Keep wire types canonical, view state local, and mapping explicit. Avoid a universal domain object that mixes persistence, transport, and UI concerns.

6

New controllers own behavior instead of merely moving functions.

Module ownershipWorking well

Evidence. mobileCatalog.ts owns catalog/profile synchronization and retry outcomes, mobileLifecycle.ts owns connection actions and stale player replacement, mobileModalStack.ts owns modal focus state, and useEpisodeNavigation.ts owns episode transition state. Discover cache/query state and media-server HTTP/library helpers also have dedicated modules.

Why it works. Inputs and outputs are typed, async outcomes are discriminated unions, and React renderers consume decisions rather than duplicating orchestration branches.

What to preserve. Keep extraction aligned with state ownership and behavior. Reject arbitrary file splitting that leaves the same implicit state graph spread across more files.
