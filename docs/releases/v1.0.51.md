# Loom Media Server 1.0.51 Release Notes

Loom Media Server 1.0.51 fixes the packaged desktop native-module build.

## Fixed

- Rebuilds `better-sqlite3` explicitly against the configured Electron runtime before desktop packaging.
- Prevents packaged runtime verification from loading a Node-ABI build instead of the Electron-ABI build.

## Verification

- `git diff --check` passes locally.
- Tagged GitHub Actions will run desktop lint, typecheck, tests, packaging, and packaged runtime verification for Windows, macOS, and Linux.
