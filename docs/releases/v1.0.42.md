# Loom Media Server 1.0.42 Release Notes

Loom Media Server 1.0.42 improves desktop playback recovery and makes macOS release validation explicit.

## Fixed

- Improves playback error handling and recovery when direct media streams fail.
- Tightens transcoding filter and stream-start behavior for unsupported or problematic media.
- Keeps continue-watching and player controls synchronized during playback transitions.
- Removes ad-hoc macOS signing from the normal package hook and adds explicit macOS release verification tools.
- Fails tagged macOS builds early when required signing and notarization credentials are missing.

## Verification

- Desktop lint and typecheck pass locally.
- Tagged GitHub Actions will run desktop tests, packaging, and packaged runtime verification for Windows, macOS, and Linux.
- Local tests were not run per repository instructions.
