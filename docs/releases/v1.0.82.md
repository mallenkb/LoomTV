# LoomTV 1.0.82 Release Notes

LoomTV 1.0.82 fixes the continue-watching thumbnail overlay.

## Highlights

- Keep continue-watching thumbnail artwork clear instead of dimming it with a permanent black overlay.
- Retain a subtle hover tint and visible play control without obscuring the thumbnail.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
