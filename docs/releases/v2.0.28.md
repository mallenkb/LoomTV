# LoomTV 2.0.28 release notes

Title pages keep the same hero height in a window and in full screen. The hero used to be a fixed 600px, which filled most of a laptop window but less than half of a full-screen display. It is now sized from your main display, so the artwork and title sit in the same place either way.

2.0.27 also changed something its notes left out. Test keys in Settings > Metadata keys now checks every key with its service, even one LoomTV had paused after timeouts. A service that answers is taken off the pause list right away, instead of showing "is not responding" until the pause ran out.
