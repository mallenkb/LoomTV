# LoomTV 1.0.155 release notes

LoomTV 1.0.155 improves release reliability and updates a production dependency to its patched version.

## Highlights

- Updates `js-yaml` to 4.3.2 to resolve the production dependency audit advisory.
- Adds bounded retries for transient Electron binary download failures during desktop packaging.
- Publishes Electron installers for macOS, Windows, and Linux.
