# LoomTV 1.0.120 Release Notes

LoomTV 1.0.120 improves metadata reliability and detail information across the desktop app.

## Highlights

- Makes metadata refreshes cache-first and safer when provider lookups return no match.
- Preserves media metadata, provider artwork choices, and provider ratings during refreshes.
- Improves detail metadata controls and the information shown for movies, TV, and anime.
- Reconciles season folders into their parent series more reliably.
- Keeps metadata refresh locking from applying stale or overlapping updates.
