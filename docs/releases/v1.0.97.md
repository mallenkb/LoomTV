# LoomTV 1.0.97 Release Notes

LoomTV 1.0.97 improves library discovery and desktop navigation.

## Highlights

- Add All, In Progress, Unwatched, Watched, Missing Metadata, and Missing Artwork filters.
- Apply library filters across the default Home page, Modern Home, and library search results.
- Improve filter menu grouping and keep selected detail tabs visually stable.
- Refine modern search placement and avoid duplicate search triggers on library pages.
- Keep top-right library controls outside Electron’s draggable title-bar region.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
