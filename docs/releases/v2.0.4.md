# LoomTV 2.0.4 release notes

- Adds Intel Mac support with architecture-matched native runtimes. Intel Macs use LibVLC, then Chromium or HLS; the bundled libmpv engine remains limited to Apple silicon on macOS 26 or later.
- Fetches pinned native runtime archives during builds and verifies their SHA-256 hashes instead of storing the large binaries in the repository.
- Restores automated desktop, server, mobile, TV, package, and Rust tests, and runs them in CI before release.
