# LoomTV 1.0.92 Release Notes

LoomTV 1.0.92 adds the hardened MPV playback path and memory-focused desktop improvements.

## Highlights

- Add a dedicated MPV playback engine with safer lifecycle management and playback fallbacks.
- Improve memory usage during library scans, artwork delivery, media serving, and playback.
- Harden stream/transcode decisions, content policy handling, and playback IPC contracts.
- Improve subtitle overlays, track controls, metadata settings, and modern home playback behavior.
- Add MPV playback helper and transcode-plan regression coverage.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop production dependency audit passes.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
