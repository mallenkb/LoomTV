# LoomTV 1.0.113 Release Notes

LoomTV 1.0.113 refreshes the desktop browsing experience and strengthens media handling.

## Highlights

- Improves Home, Discover, My List, metadata, anime cast, provider, and trailer experiences.
- Refines playback controls, library scanning, profiles, onboarding, and desktop navigation.
- Adds safer media, LAN, IPC, and native-runtime handling across the desktop app.
