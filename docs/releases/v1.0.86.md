# LoomTV 1.0.86 Release Notes

LoomTV 1.0.86 fixes the actual cause of the Modern detail hero positioning bug that 1.0.84 and 1.0.85 did not fully resolve.

## Highlights

- Stop centering the desktop hero backdrop with a `-translate-x-1/2` transform. The CSS minifier folds any `translate` reset into a sibling `transform` declaration in the same rule and drops it, so the resets shipped in 1.0.84 and 1.0.85 never survived the production build.
- Center the backdrop with `left: 0; right: 0; margin-inline: auto` instead, which needs no transform to override.
- Restore complete movie, TV, and anime backdrops across the desktop hero.

## Verification

- Verified the corrected desktop hero directly in a local Electron build with Computer Use, on both a TV/anime title and a movie title.
- Inspected the built (minified) CSS and JS bundles directly to confirm the transform-cancelling rules are gone and the new centering classes are present.
- Desktop ESLint and TypeScript checks pass.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
