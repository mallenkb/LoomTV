# LoomTV 1.0.102 Release Notes

LoomTV 1.0.102 adds the first headless NAS/server foundation and shared media runtime capabilities while making desktop release publishing reliable across platforms.

## Highlights

- adds a headless server with NAS-aware health, scanning, streaming, transcoding, and browser administration
- shares media identity, playback profiles, runtime paths, and transcoding capability detection between desktop and server runtimes
- improves desktop library, metadata, media probing, profile, and transcoding boundaries
- publishes macOS, Windows, and Linux artifacts through a single release upload step to avoid GitHub release races
