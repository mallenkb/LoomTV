# LoomTV 2.0.8 release notes

- Resolves a title's IMDb identity before online subtitle search when the library item is missing that ID.
- Uses series-appropriate metadata and prioritizes TV database years so movie matches do not override a show's year.
- Adds safeguards to media organization and rename planning.
- Applies the nested `DigestAlgorithm` validation fix from upstream node-forge PR #1152 while a fixed upstream release is pending.
