# LoomTV 2.0.10 release notes

- Opens the desktop window before canonical administration finishes and adds main-process and renderer code caches. Existing renderer preferences migrate to the new application origin.
- Moves artwork decoding, FFprobe, FFmpeg capability checks, and LibVLC input teardown off the Electron main thread. Shutdown and update installation wait for teardown workers to finish.
- Skips duplicate native playback state updates and reduces paused LibVLC polling.
- Retains recently viewed and prefetched details briefly within bounded query caches, with up to three concurrent hover prefetches.
- Prevents folder organization while video or non-video files are still being written, with consistent partial-download markers and Finder metadata handling.
- Records startup milestones and main-thread stalls for diagnosis, and adds CI guards for scan persistence and projection performance.
- Patches excessive nesting in the braces dependency and updates dependency-audit handling.

This release publishes Electron desktop installers for macOS, Windows, and Linux. It does not publish Tauri or mobile binaries.
