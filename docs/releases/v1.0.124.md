# LoomTV 1.0.124 Release Notes

LoomTV 1.0.124 refreshes the complete desktop release for macOS, Windows, and Linux with more reliable packaging and publication.

## Highlights

- Retries transient fpcalc and Electron download failures during desktop packaging with bounded backoff and per-attempt timeouts.
- Gives the multi-platform publisher enough time to upload and verify the complete release asset set.
- Ships custom media libraries, responsive artwork selection, and the Windows native-module packaging fix across every desktop package.
