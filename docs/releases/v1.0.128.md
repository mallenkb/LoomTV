# LoomTV 1.0.128 Release Notes

LoomTV 1.0.128 refines the desktop interface and playback experience across the home page, detail views, discovery, and video player.

## Highlights

- Improves hero actions, metadata, artwork fallbacks, provider marks, content ratings, and watched-state controls.
- Refines home rails, poster cards, library filters, plugin discovery, onboarding, and theme customization.
- Adds richer video-player controls and system media-key integration across supported playback engines.
- Strengthens desktop IPC and playback protocol handling, including metadata schema validation and toast feedback.
- Refreshes verified desktop packages for macOS, Windows, and Linux.
