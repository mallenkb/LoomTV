# LoomTV 1.0.100 Release Notes

LoomTV 1.0.100 strengthens desktop security and continues the Modern layout cleanup.

## Highlights

- Harden paired-network trust, profile authorization, renderer bootstrap, playback sessions, and subtitle delivery boundaries.
- Refine responsive Modern layout geometry, playback overlays, reduced-motion behavior, accessibility, and library filters.
- Remove obsolete production audit waivers and add generated-policy and behavioral boundary verification.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
