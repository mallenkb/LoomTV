# LoomTV 1.0.69 Release Notes

LoomTV 1.0.69 polishes desktop navigation and in-app updates.

## Highlights

- Show local navigation sections only when the corresponding library folders are linked, while keeping the full navigation available for remote clients.
- Restore connected-library navigation and improve remote-library projection behavior.
- Add a clearer download progress fill and status text to the sidebar update control.
- Refine desktop window chrome and onboarding presentation.
- Simplify the About settings update control and keep profile and playback fixes from the previous desktop release line.

## Verification

- Desktop release CI validates linting, typechecking, tests, installer builds, and packaged runtime dependencies on macOS, Windows, and Linux.
