# LoomTV 2.0.16 release notes

- Replaces the next-episode banner with a compact calendar card above the season list.
- Shows the episode code, such as S02E01, beside the weekday and a larger countdown. Episodes airing today or tomorrow use those labels instead of a day count.
- Makes the calendar month easier to read with a solid theme accent and high-contrast text. The card uses a subtle theme tint without an outline.
- Keeps the text compact and matches the left, top, and bottom padding at 8.8 pixels.

Includes the metadata, playback, library recovery, and dependency updates from 2.0.15.

This release publishes Electron desktop installers for macOS, Windows, and Linux. It does not publish Tauri or mobile binaries.
