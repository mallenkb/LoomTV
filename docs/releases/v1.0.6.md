# LoomTV 1.0.6 Release Notes

LoomTV 1.0.6 focuses on theme customization, cleaner settings, and smoother library navigation.

## What's new

- Added dark theme choices for Black, Default, and Navy Black.
- Added logo colour options and loader style previews.
- Added an Others library section, side-nav item, and page for mixed media folders.
- Added season-count metadata on show cards where local seasons are available.

## Improvements

- Refined settings layout, buttons, panels, dialogs, and metadata picker styling to follow the active theme.
- Improved continue-watching bar density and typography.
- Preserved theme choices across reloads.
- Kept rating badges consistently gold across all themes.
- Added database migration support for Others folders.

## Fixes

- Fixed Settings crashes when older library data did not include the Others folder group.
- Fixed local database saves failing when an Others folder was present.
- Fixed metadata picker backdrop dismissal and close button placement.
- Reset subtitle defaults to 32px size and 96% position.

## Build

- Bumped the app version to `1.0.6`.
