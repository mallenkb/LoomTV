# LoomTV 1.0.75 Release Notes

LoomTV 1.0.75 refreshes desktop discovery and the Modern viewing experience.

## Highlights

- Add discovery-first pairing and clearer host/remote onboarding flows.
- Refresh the Modern home, media rails, TV detail pages, library navigation, and artwork controls.
- Improve profile gating, profile-aware settings, and playback/player overlays.
- Add stronger confirmation and error-boundary handling around desktop interactions.
- Improve metadata, artwork URL handling, and LAN protocol compatibility.
- Update the workspace to pnpm 11.17.0 for consistent desktop builds.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
