# LoomTV 1.0.70 Release Notes

LoomTV 1.0.70 fixes packaged desktop update configuration.

## Highlights

- Ensure macOS, Windows, and Linux packaged apps contain the GitHub update provider metadata required by electron-updater.
- Prevent packaged update checks from throwing when update metadata is unavailable.
- Preserve the navigation and update-progress improvements from the previous desktop release.

## Verification

- Desktop lint and typecheck pass locally.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
