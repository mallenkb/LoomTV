# LoomTV 1.0.93 Release Notes

LoomTV 1.0.93 improves desktop library performance, playback navigation, LAN behavior, and update cleanup.

## Highlights

- Improve library scanning, projection, probing, media serving, and artwork handling for larger collections.
- Add shared list highlighting and lazy video loading to make library and episode navigation smoother.
- Harden playback IPC, stream/transcode handling, updater cleanup, and packaged media-server behavior.
- Refresh desktop library, settings, sidebar, home, and detail-view interactions.
- Improve shared LAN protocol behavior and mobile library-domain integration.
- Keep the active modern category tab fixed while using opacity-only hover feedback on inactive tabs.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop production dependency audit passes.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
