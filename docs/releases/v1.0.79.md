# LoomTV 1.0.79 Release Notes

LoomTV 1.0.79 publishes the complete desktop installer set.

## Highlights

- Include the desktop discovery, pairing, Modern experience, profile, artwork, onboarding, and playback improvements.
- Use pnpm 11.17.0 and the patched `electron-updater` 6.8.9 / `builder-util-runtime` 9.7.0 dependency chain.
- Publish complete macOS, Windows, and Linux installers with updater metadata.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop production dependency audit passes.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
