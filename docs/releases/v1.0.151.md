# LoomTV 1.0.151 release notes

LoomTV 1.0.151 updates the Electron desktop app and fixes macOS runtime verification for the bundled libmpv player.

## Highlights

- Verifies the bundled libmpv library and LoomTV native bridge at their current packaged paths.
- Removes obsolete external-mpv packaging entries.
- Publishes refreshed macOS, Windows, and Linux Electron installers with updater manifests.
