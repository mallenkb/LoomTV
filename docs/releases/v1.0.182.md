# LoomTV 1.0.182

## Desktop release

- Adds local outro detection for TV and anime episodes, with silence, keyframe, and chapter boundary snapping.
- Adds an opt-in SkipDB fallback provider for TV, anime, and movies behind the experimental provider flag.
- Adds a verified-marker evidence tier, conferred by exact-file detectors and timestamp manager approval.
- Hardens the player Skip action with click-time revalidation, pinned targets, and protected pre-roll behavior.
- Adds bulk review approval to the skip timestamp manager.
