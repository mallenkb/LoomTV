# Loom Media Server 1.0.47 Release Notes

Loom Media Server 1.0.47 improves the desktop intro/outro skipping experience.

## Changed

- Makes automatic intro and outro detection the primary playback-settings action.
- Moves advanced analysis options, exclusions, maintenance controls, and scoped scans behind an advanced section.
- Makes manual timestamp editing available from a dedicated, on-demand panel.
- Adds clearer labels for analysis status states.

## Verification

- Desktop lint and typecheck pass locally.
- Tagged GitHub Actions will run desktop tests, packaging, and packaged runtime verification for Windows, macOS, and Linux.
- Local tests were not run per repository instructions.
