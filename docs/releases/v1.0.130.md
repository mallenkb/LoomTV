# LoomTV 1.0.130 Release Notes

LoomTV 1.0.130 packages the current unified platform work and the fixes needed for a clean desktop release build.

## Highlights

- Unifies desktop, mobile, and server playback paths around the canonical video platform APIs.
- Improves LibVLC startup, native playback warmup, scrubbing, and fallback behavior.
- Hardens metadata provider fallbacks and onboarding flows when provider data is incomplete.
- Adds local TLS certificate download guidance for paired clients.
- Fixes desktop and mobile lint and typecheck failures in release validation.
- Refreshes the verified desktop packages for macOS, Windows, and Linux.
