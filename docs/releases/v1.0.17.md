# Loom Media Server 1.0.17

Loom Media Server 1.0.17 keeps unsupported local videos inside the app instead of trying to open a separate MPV player window.

## Playback

- Sends files that Chromium cannot direct-play straight to the in-app local stream/transcode path.
- Prevents the player from auto-opening a separate native MPV window for unsupported formats.
- Keeps Loom Media Server's custom controls attached to the active video surface more consistently.

## Cleanup

- Removes the unused embedded-MPV experiment code path from the MPV controller.
- Adds a README playback roadmap note for future `libmpv` native addon work.
