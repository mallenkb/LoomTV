# LoomTV 1.0.142 Release Notes

LoomTV 1.0.142 improves desktop artwork selection, playback, metadata, and Live TV support.

## Highlights

- Adds richer cover and provider handling across desktop metadata and artwork flows.
- Improves movie and series playback integrations, including Vidking playback references.
- Adds a secure IPTV stream proxy for HLS playlists and media resources.
- Refines desktop detail pages, poster cards, sidebar states, and video-player controls.
- Hardens desktop IPC, media-server, metadata, and runtime decoding paths.
