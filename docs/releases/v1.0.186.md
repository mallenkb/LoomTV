# LoomTV 1.0.186 release notes

LoomTV 1.0.186 returns cache memory when the app is idle or hidden, and never while anything plays.

## Highlights

- Clears the shared probe cache and renderer Blink caches after 5 minutes without input.
- Trims 30 seconds after the window is hidden or minimized.
- Skips trimming while a player is open or any media session is playing.
- Keeps LibVLC prewarmed, first for local files, and unchanged for IPTV.
