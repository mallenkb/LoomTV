# LoomTV 1.0.103 Release Notes

LoomTV 1.0.103 completes mixed-video library support and advances the paired mobile companion while tightening release validation.

## Highlights

- adds user-configured mixed/Others roots to desktop, LAN, and mobile library projections with duplicate-safe aggregate views
- expands the mobile companion with offline metadata recovery, installable EAS preview/production profiles, and a release checklist
- adds tracked mobile release-contract validation to the desktop release workflow
- updates the desktop and headless server packages to 1.0.103
