# LoomTV 2.0.6 release notes

- Fixes TV invitation playback authorization and HLS startup, preserves playback position and tracks across recovery, and cleans up failed or stale playback leases.
- Bounds iOS and Android proxy buffering and connections, and cancels mobile downloads when profiles change, lock, or unmount.
- Improves PIN recovery and sign-in checks while limiting concurrent authentication work.
- Preserves content ratings through library scans so parental filters continue to work after reopening the app.
- Retains HLS playlist segments for the session and uses paced delivery to reduce storage and playback issues.
