# LoomTV 1.0.143 Release Notes

LoomTV 1.0.143 improves desktop artwork, metadata, theming, and playback presentation.

## Highlights

- Refines artwork candidate selection and cover/logo handling across metadata providers.
- Keeps TMDB logo fallback candidates bounded for predictable metadata results.
- Updates artwork editor and detail-page actions for a more consistent desktop experience.
- Improves theme, plugin discovery, and detail-page rendering behavior.
- Hardens desktop media-server, IPC, decoder, and metadata integration paths.
- Removes the obsolete Vidking playback helper and its unused integration surface.
- Updates Browserslist and related browser data packages to patched versions.
