# LoomTV 1.0.65 Release Notes

LoomTV 1.0.65 expands the mobile companion experience for paired profile-aware playback.

## Highlights

- Add mobile profile selection with avatar cards, active-profile state, and PIN-protected unlock.
- Load profile preferences and personal lists from the paired desktop, with profile-aware requests and selection revisions.
- Add profile switching, automatic sign-in, lock, and About/settings sections to the mobile app.
- Improve LAN discovery, saved-session reconnects, credential refresh, and pairing request compatibility.
- Distinguish Outro, Credits, Preview, Intro, and Recap skip markers on mobile playback.
- Polish mobile playback controls, subtitles, progress behavior, theme colors, splash presentation, and home/detail metadata.
- Add open-source attribution and DiceBear Glyphs licensing notices for the mobile app.

## Verification

- Mobile ESLint and TypeScript checks pass with zero errors and warnings.
- Desktop release CI packages macOS, Windows, and Linux installers and verifies packaged runtime dependencies.
