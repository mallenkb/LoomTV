# LoomTV 2.0.18 release notes

Republishes the Electron desktop app as 2.0.18, with no app-code changes since 2.0.17. It includes the compact next-episode calendar card, 20-pixel countdown padding, and earlier metadata, playback, library recovery, and dependency fixes.

This release publishes Electron desktop installers for macOS, Windows, and Linux. It does not publish Tauri or mobile binaries.
