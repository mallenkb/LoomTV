# LoomTV 1.0.71 Release Notes

LoomTV 1.0.71 introduces a new cinematic desktop experience while preserving the familiar default layout.

## Highlights

- Add an optional Modern home with a cinematic hero carousel, media rails, Continue Watching, and full-library search.
- Add floating category navigation, compact profile controls, and modern movie and TV detail presentation.
- Let viewers choose Default or Modern during onboarding and from Theme settings, with profile-aware persistence across local and paired clients.
- Improve profile-gate routing, player chrome behavior, artwork controls, settings layout, and responsive spacing.
- Remove visual update progress bars while retaining clear download percentage text and status icons.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
