# Loom Media Server 1.0.43 Release Notes

Loom Media Server 1.0.43 adds desktop-owned skip-marker analysis and improves TV playback flow handling.

## Added

- Detects and resolves intro, recap, credits, and preview markers using provider data and local analysis.
- Adds skip-marker playback prompts and editor/settings controls for desktop TV and anime playback.
- Bundles the platform fingerprint helper used by local media analysis.
- Adds database persistence, normalization, provider fallback, and file-release matching for markers.

## Fixed

- Tightens playback state, clock, stream preparation, and media scanning behavior around TV playback transitions.
- Adds coverage for marker resolution, playback timing, anime season mapping, and packaged runtime dependencies.

## Verification

- Desktop lint and typecheck pass locally.
- Tagged GitHub Actions will run desktop tests, packaging, and packaged runtime verification for Windows, macOS, and Linux.
- Local tests were not run per repository instructions.
