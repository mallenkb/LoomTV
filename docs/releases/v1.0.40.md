# Loom Media Server 1.0.40 Release Notes

Loom Media Server 1.0.40 makes library rescans preserve the metadata and artwork already chosen for local media.

## Fixed

- Keeps existing titles, artwork, metadata candidates, provider IDs, playback history, and episode details while refreshing filesystem-derived scan data.
- Preserves episode and season state when a series folder is rescanned.
- Reuses valid cached scans for unchanged folders, including full scans, to avoid unnecessary metadata replacement.

## Verification

- GitHub Actions will run the desktop lint, typecheck, test, packaging, and packaged-runtime checks for the tagged release.
- Local tests were not run per repository instructions.
