# Loom Media Server 1.0.40 Release Notes

Loom Media Server 1.0.40 makes update publishing reliable across macOS, Windows, and Linux.

## Fixed

- Collects every platform installer and updater manifest before publishing the GitHub release, following the proven Fellow Show release pattern.
- Prevents users from seeing a partially published release that is still missing `latest-mac.yml`.
- Treats a temporarily unavailable update feed as non-fatal instead of displaying raw HTTP headers and an internal stack trace.
- Replaces technical updater failures with a concise, actionable message.

## Verification

- GitHub Actions will run the desktop lint, typecheck, test, packaging, and packaged-runtime checks for the tagged release.
- Local tests were not run per repository instructions.
