# LoomTV 1.0.19

LoomTV 1.0.19 tightens the update install path and cleans up the Settings experience around updates and metadata keys.

## Updates

- Drains active transcodes and media server connections before installing a downloaded update.
- Lets Electron's updater own the restart sequence, with a fallback quit if shutdown does not begin.
- Prevents app activation or second-instance handling from reopening LoomTV while an update install is in progress.
- Keeps update checking, download progress, and restart state on the same Settings button.

## Settings

- Removes provider-specific wording from the visible update status copy.
- Makes the About update button hug its label instead of stretching across the card.
- Moves FFmpeg status under the LoomTV About description.
- Removes the duplicate divider in Metadata API Keys.

## Tests

- Adds coverage for force-closing active media server connections during update install.
