# LoomTV 1.0.16

LoomTV 1.0.16 is a focused patch for episode metadata titles in series playback.

## Series Metadata

- Fixes episode metadata merging during library scans so fetched episode names attach to the correct local files.
- Keeps metadata titles that include an episode code prefix, such as `S01E03 - Title`, instead of collapsing them to `Episode 3`.
- Updates the player episode drawer to show the cleaned metadata title for each episode.
- Uses the same metadata-aware title display in the current episode badge and Up Next prompt.

## Notes

- Restart the app and refresh metadata or rescan affected series if old generic episode names were already saved locally.
