# LoomTV 1.0.176 release notes

LoomTV 1.0.176 lowers idle memory while keeping LibVLC warm and first for local playback.

## Highlights

- Loads the libmpv bridge only when playback actually selects it.
- Bounds library and renderer caches with idle expiry instead of holding full snapshots.
- Removes idle route and player preloads; routes and the player load on use.
- Defers automatic scans while the app is hidden or playback is active.
- Keeps LibVLC prewarmed, first for local files, and unchanged for IPTV.
