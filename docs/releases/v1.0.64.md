# LoomTV 1.0.64 Desktop Release Notes

LoomTV 1.0.64 streamlines desktop profiles, personal lists, and local-network browser access.

## Highlights

- Switch profiles directly from the sidebar, with PIN-protected selection and shortcuts to add or manage profiles.
- Open profile creation and editing at the intended screen, with clearer navigation and save controls.
- Combine Watchlist and Favorites into one deduplicated **My List** across Home and media details.
- Support profile selection, preferences, and personal lists consistently in desktop browser mode.
- Open the browser interface through the computer's LAN address and allow its development WebSocket connection.
- Refresh theme color names and polish profile hover, selection, and current-profile states.

## Verification

- Desktop lint and renderer/main TypeScript checks pass with zero errors and warnings.
- Tagged GitHub Actions runs the complete desktop test suite and packages macOS, Windows, and Linux installers.
