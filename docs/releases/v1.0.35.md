# Loom Media Server 1.0.35

This patch release fixes the Electron Settings experience so tab clicks stay responsive and the top chrome no longer steals interaction from tabs or actions.

## Fixes

- Keeps the Settings tab strip clickable inside the macOS drag band.
- Makes tab changes apply immediately instead of deferring them behind background work.
- Defers Electron-only Settings probes until the relevant tab is active.
- Avoids synchronous Wi-Fi name probing and duplicate FFmpeg discovery in the desktop app.
