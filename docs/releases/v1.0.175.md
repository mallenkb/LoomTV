# LoomTV 1.0.175 release notes

LoomTV 1.0.175 restores the 1.0.172 playback path with LibVLC as the default local engine.

## Highlights

- Tries LibVLC first for local files, with libmpv as the fallback.
- Keeps the LibVLC process prewarm on desktop startup.
- Keeps the proven 1.0.172 update adapter behavior.
