# LoomTV 1.0.119 Release Notes

LoomTV 1.0.119 makes watched status accurately follow playback completion and restores embedded trailer playback.

## Highlights

- Automatically marks movies and complete TV or anime series as watched when every available file has been watched.
- Lets you mark completed titles as unwatched, clearing their completed playback progress so they leave the Watched list.
- Returns a series to its normal state when new, unwatched episodes are added.
- Fixes YouTube trailer Error 153 in the packaged desktop app.
