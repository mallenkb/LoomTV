# LoomTV 1.0.135 Release Notes

LoomTV 1.0.135 adds Live TV sources to the desktop app.

## Highlights

- Adds HTTPS M3U/M3U8 playlist sources with optional XMLTV guide data, refresh status, and safe parsing.
- Adds one Live TV tab per source with channel search, category and geo filters, sorting, pagination, logos, and current and next programme details.
- Adds live-channel playback behavior, including live-edge controls and channel identity in the pause state.
- Adds settings and database migrations for managing Live TV sources and channels.
- Includes the verified desktop packages for macOS, Windows, and Linux.
