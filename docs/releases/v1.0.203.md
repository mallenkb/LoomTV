# LoomTV 1.0.203 release notes

LoomTV 1.0.203 improves new-media discovery, episode tracking, metadata scans, and file organization.

## Highlights

- Adds "Newly Added," "New Episode," and "New Season" badges, and moves those titles earlier in Home rails.
- Shows aired episodes missing from local seasons on TV detail pages, with available artwork and episode summaries.
- Tracks first-seen dates for titles and episodes. Bulk library imports do not receive new badges.
- Improves episode-number parsing and metadata matching during scans, and avoids renaming files that already use LoomTV's organized naming.
- Uses automatic file organization when no saved preference exists. Existing "Ask me" and "Off" choices remain unchanged.
- Adds renderer API fallbacks for library insights and Live TV guide actions.
