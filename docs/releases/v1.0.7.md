# Loom Media Server 1.0.7 Release Notes

Loom Media Server 1.0.7 is a patch release for the library folder and update install flows introduced around 1.0.6.

## Fixed

- Fixed library scans so in-progress scan snapshots no longer overwrite the saved library database.
- Fixed adding folders to Movies, TV Shows, Anime, and Others so existing scanned items and scan cache are preserved until the final scan completes.
- Fixed scan progress events to show the live scan snapshot without persisting partial data.
- Added an explicit installing/restarting update state after a downloaded update is applied.

## Changed

- Bumped the app version to `1.0.7`.
