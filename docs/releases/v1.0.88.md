# LoomTV 1.0.88 Release Notes

LoomTV 1.0.88 makes startup feel faster, improves desktop tray reliability, and strengthens the shared LAN foundation used by desktop and mobile players.

## Highlights

- Paint the cached library first, then hydrate artwork, playback progress, settings, and the startup scan in the background.
- Defer non-critical desktop services until after the main window opens and clean stale transcodes asynchronously.
- Ship dedicated standard and Retina tray assets, preserve their native representations, and verify them in packaged builds.
- Consume the LAN protocol as a shared workspace package from both desktop and mobile instead of importing its source through relative paths.
- Accept the opaque signed resource IDs produced by the desktop media server in the mobile library client.
- Run linting, type checks, and tests across the full workspace in installer CI.
- Keep Modern detail artwork inside the same centered max-width frame used by the home hero on ultrawide displays.
- Resolve persisted audio and subtitle preferences against each episode's tracks before playback starts, avoiding wrong-track playback and subtitle timing mismatches during episode changes.

## Release validation

- Local static validation covers the workspace diff and TypeScript configuration.
- GitHub release CI runs workspace linting, type checks, and tests before building installers.
- Packaged runtime verification checks native dependencies, media tools, update metadata, and the new tray assets on macOS, Windows, and Linux.
