# LoomTV 2.0.14 release notes

Republishes the Electron desktop app as 2.0.14, with no app-code changes since 2.0.13. It includes the Cinemeta year fix and the metadata, playback, library recovery, and dependency fixes from that release.

This release publishes Electron desktop installers for macOS, Windows, and Linux. It does not publish Tauri or mobile binaries.
