# LoomTV 1.0.127 Release Notes

LoomTV 1.0.127 improves desktop playback, presentation, and local-network reliability while strengthening the companion mobile connection experience.

## Highlights

- Improves LAN discovery, host address selection, and network settings for more reliable desktop-to-mobile connections.
- Refines playback progress handling, TV detail controls, skip-segment coordination, and profile state updates.
- Improves artwork fallbacks, rating badges, home presentation, and theme customization.
- Adds stronger mobile diagnostics, offline persistence, secure transport handling, and connection lifecycle controls.
- Refreshes verified desktop packages for macOS, Windows, and Linux.
