# LoomTV 2.0.13 release notes

- Uses Cinemeta as the default for new movie, anime, and TV metadata when the title matches. The live endpoint supplies IMDb ratings, artwork, summaries, and useful episode names; other providers fill missing fields and local artwork keeps priority.
- Loads TheTVDB titles, summaries, and episode names in English. Metadata and artwork pickers show Cinemeta first, followed by the recommended providers for the media type.
- Makes artwork selection buttons smaller and adds a hover gradient that darkens behind the button.
- Adds configurable rewind on resume across desktop playback engines and preserves the preference across profiles and clients.
- Supports organizing a selected original import and improves original-file inventory, recovery, and cleanup handling.
- Includes faster scans, provider timeouts, broader trailer and episode-rating coverage, and episode-number matching improvements from the latest main branch.
- Updates source-map-js to 1.2.2 and compression to 1.8.2 to address dependency vulnerabilities.

Versions 2.0.11 and 2.0.12 were not published. This release includes their changes and corrects the playback test harnesses.

This release publishes Electron desktop installers for macOS, Windows, and Linux. It does not publish Tauri or mobile binaries.
