# LoomTV 1.0.112 Release Notes

LoomTV 1.0.112 improves desktop discovery and anime title details.

## Highlights

- Adds Discover content directly in the Home and Modern Home flows so browse flows appear when local content is empty or filtered out.
- Adds streaming platform and region filtering for movie and TV discover results, with dynamic provider discovery.
- Expands anime discover metadata with richer character and voice-actor credit data and adds an improved desktop cast layout.
- Improves discover state handling by keeping return routes and cache entries aligned with the current selection and session state.
