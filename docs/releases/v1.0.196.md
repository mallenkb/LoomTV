# LoomTV 1.0.196 release notes

LoomTV 1.0.196 adds tools for tracking episodes, checking library health, and controlling live TV playback.

## Highlights

- Home and show pages surface new episodes, recently added titles, upcoming air dates, and aired episodes missing from the library.
- Library settings can report unmatched titles, missing episodes, shows split across folders, files without subtitles, and files skipped by renaming.
- The live TV player adds channel switching and clearer playback problems. After two automatically completed episodes without viewer input, playback asks whether to continue.
