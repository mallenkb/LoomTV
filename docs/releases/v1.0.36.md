# Loom Media Server 1.0.36

This patch release continues the Settings responsiveness work and reduces maintenance risk in the desktop app by extracting large UI/main-process pieces and removing dead code.

## Improvements

- Splits Settings tab content into focused section components while keeping the tab strip clickable inside the macOS drag band.
- Moves Electron IPC handler registration out of the main-process monolith without changing the registered channel surface.
- Extracts VideoPlayer pause overlay and top controls into focused memoized components.
- Removes unused exports, stale helper code, and unused workspace catalog entries.
- Adds a future-work note for safe renderer bundle splitting that avoids touching the video playback path.
