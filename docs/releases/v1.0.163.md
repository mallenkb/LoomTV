# LoomTV 1.0.163 release notes

LoomTV 1.0.163 keeps initial library setup focused on the default video categories and tidies the metadata source list.

## Highlights

- Streamlines Movies, TV Shows, Anime, and Other folders in setup and Settings.
- Moves Cinemeta / Stremio and OpenSubtitles v3 / Stremio attribution cards to the end.
- Removes the duplicate plain OpenSubtitles attribution card.
