# LoomTV 1.0.58 Release Notes

LoomTV 1.0.58 republishes the desktop viewer-profile release with current migration verification.

## Fixed

- Updates the migration test ledger to include profile feature schema version 2.
- Retains the corrected guest-device profile listing and editable profile type narrowing from 1.0.57.
- Restores the complete desktop release pipeline after the stale migration assertion blocked installer generation.

## Included

- Viewer profile creation, editing, deletion, avatars, profile switching, and optional PIN protection.
- Profile-specific Continue Watching history and playback progress.
- Safer progress flushing and playback handoffs when switching viewers.

## Verification

- Tagged GitHub Actions validates desktop lint, typechecking, all 172 tests, packaging, packaged runtime dependencies, and artifact upload on macOS, Windows, and Linux.
