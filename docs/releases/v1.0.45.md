# Loom Media Server 1.0.45 Release Notes

Loom Media Server 1.0.45 makes desktop skip-marker lookups durable across provider refreshes and playback startup.

## Fixed

- Preserves verified provider timestamps for the current file revision when later responses are empty or partial.
- Retries empty or failed marker lookups during playback so markers that arrive after startup become available.
- Lets AniSkip and TheIntroDB fill missing intro or credits marker types without erasing valid results.
- Keeps active playback waiting for the bounded marker lookup before returning the initial segment response.
- Protects stored markers for media items during orphan cleanup while still removing stale file revisions.

## Verification

- Desktop lint and typecheck pass locally.
- Tagged GitHub Actions will run desktop tests, packaging, and packaged runtime verification for Windows, macOS, and Linux.
- Local tests were not run per repository instructions.
