# LoomTV 2.0.31 release notes

## Add-on playback and episode tracking

- Track episode progress across playback sources and resume from your saved position.
- Choose sources for individual episodes or switch sources inside the player.
- Continue to the next episode across seasons, with a preference for your previous provider and quality.
- See resume progress and watched indicators in episode lists.
- Find streaming, purchase and rental options in a compact dropdown, with provider logos and country selection.
- Improve add-on details with richer metadata, cast portraits and additional ratings, including OMDb ratings with MDBList fallback.
- Refine loading indicators, dialogs and source-selection layouts.

## Additional changes

- Adds opt-in peer-to-peer streaming for supported Stremio add-ons, using host-controlled sessions and LoomTV's local media relay.
- Adds Rotten Tomatoes and Metacritic scores when the configured providers return them.
- Adds selectable player control styles and loading animations in Appearance, with refinements to control spacing, sizing, hover behavior and previews.
- Removes the vulnerable `ip` helper from the patched UDP tracker parser and formats announce addresses directly.

## Verification status

End-to-end playback, visual checks and packaged-app verification remain pending.
