# LoomTV 2.0.31 release notes

- Adds opt-in torrent playback for supported Stremio add-ons, using host-controlled sessions and LoomTV's local media relay.
- Aligns add-on detail pages with local metadata pages, including cast portraits and OMDb ratings with MDBList fallback.
- Adds Rotten Tomatoes and Metacritic scores when the configured providers return them.
- Adds selectable player control styles and loading animations in Appearance, with refinements to control spacing, sizing, hover behavior and previews.
- Removes the vulnerable `ip` helper from the patched UDP tracker parser and formats announce addresses directly.
