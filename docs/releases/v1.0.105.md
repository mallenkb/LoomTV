# LoomTV 1.0.105 Release Notes

LoomTV 1.0.105 bundles the desktop native playback runtime and consolidates playback, memory, mobile, and server hardening changes from the current release work.

## Highlights

- adds bundled LibVLC and MPV runtime packaging with attribution and runtime verification
- improves desktop local playback controls, subtitles, fullscreen behavior, scrubbing, and playback diagnostics
- reduces unnecessary startup and library memory work while preserving playback fallbacks
- refreshes mobile LAN transport and release configuration safeguards
- aligns CI with the repository's pnpm 11.20.0 toolchain
