# LoomTV 1.0.110 Release Notes

LoomTV 1.0.110 improves desktop playback fallback behavior and macOS packaging compatibility.

## Highlights

- signs bundled MPV ad-hoc builds without hardened-runtime flags so MPV can load its own libraries on macOS
- avoids probing the optional MPV fallback when LibVLC is already available
- clarifies playback settings when MPV has not been checked and removes redundant startup probing/logging
