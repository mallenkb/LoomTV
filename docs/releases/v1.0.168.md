# LoomTV 1.0.168 release notes

LoomTV 1.0.168 improves Electron playback reliability and library scanning.

## Highlights

- Refreshes subtitles responsively during playback while avoiding unnecessary animation-frame work when paused.
- Improves player shutdown, resume-progress saves, and cleanup of obsolete stream sessions.
- Releases prepared artwork resources when an artwork selection is replaced or fails to load.
- Enables automatic selection of the bundled scanner for eligible scans.
