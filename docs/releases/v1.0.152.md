# LoomTV 1.0.152 release notes

LoomTV 1.0.152 removes the legacy OpenSubtitles API-key setup from the Electron desktop app.

## Highlights

- Keeps OpenSubtitles v3 subtitle search built into the player without an API key.
- Removes the unused API-key, account, language, and automatic-download settings.
- Publishes refreshed macOS, Windows, and Linux Electron installers with updater manifests.
