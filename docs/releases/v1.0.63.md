# LoomTV 1.0.63 Desktop Release Notes

LoomTV 1.0.63 adds a first-run desktop setup choice and improves end-of-episode skip markers.

## Highlights

- Choose whether a desktop starts a local library or connects to an existing LoomTV host.
- Discover hosts automatically or connect manually with an address and six-digit pairing PIN.
- Use profiles, library data, playback progress, preferences, streams, transcoding, and skip markers from the paired host.
- Keep host administration on the host computer while remote desktops use personal settings.
- Separate episode endings as **Outro** markers from production Credits, with distinct Outro, Credits, and Preview prompts.
- Migrate existing AniSkip ending markers safely and avoid long fallback network scans on Windows.

## Verification

- Desktop lint and TypeScript checks pass.
- The release workflow runs the complete desktop test suite and packages macOS, Windows, and Linux installers.
