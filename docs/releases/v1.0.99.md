# LoomTV 1.0.99 Release Notes

LoomTV 1.0.99 fixes the desktop Modern library layout.

## Highlights

- Keep the final library row clear of the fixed Continue Watching bar.
- Align the playback bar and library gutters with Modern Home's responsive content frame.
- Share the same page shell across Movies, TV Shows, Anime, and custom Others folders.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
