# LoomTV 1.0.22

This release fixes macOS restart-to-update for the current ad-hoc signed release channel.

## Updates

- Adds a macOS install fallback that verifies the downloaded update checksum, extracts the release zip, replaces `/Applications/LoomTV.app`, and relaunches LoomTV.
- Avoids getting stuck when Squirrel.Mac rejects an ad-hoc signed update before closing the app.

## Verification

- Local checks cover linting, TypeScript, unit tests, packaged runtime dependencies, and packaged renderer asset paths.
