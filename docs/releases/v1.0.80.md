# LoomTV 1.0.80 Release Notes

LoomTV 1.0.80 refines artwork management, playback preferences, and desktop update feedback.

## Highlights

- Replace the artwork refresh menu with focused poster and cover repair actions, plus clearer upload options.
- Remember audio and subtitle choices as profile defaults while retaining media-specific preferences.
- Show update download progress inside the existing sidebar and About controls without a separate progress bar.
- Restore the standard player chrome in Modern mode while keeping rounded controls.
- Refine TV detail artwork actions, About update feedback, and home artwork blending.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop production dependency audit passes.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
