# LoomTV 1.0.123 Release Notes

LoomTV 1.0.123 refreshes the complete desktop release for macOS, Windows, and Linux.

## Highlights

- Ships custom media libraries and folder organization across every desktop package.
- Includes the responsive artwork grid with provider tags and direct cover selection.
- Includes the Windows native-module packaging fix from the previous desktop release.
- Extends the release publisher timeout so large multi-platform uploads can finish without leaving a partial draft.
