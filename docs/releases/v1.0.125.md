# LoomTV 1.0.125 Release Notes

LoomTV 1.0.125 improves desktop browser-host behavior, artwork editing, and navigation across macOS, Windows, and Linux.

## Highlights

- Preserves host mode in a browser renderer when the running local catalog confirms an existing setup.
- Routes browser artwork and incomplete-metadata actions through authenticated renderer endpoints.
- Fixes active-state tracking for custom-folder navigation items.
- Refines the responsive artwork chooser and modern detail artwork sizing.
