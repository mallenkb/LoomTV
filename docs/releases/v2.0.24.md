# LoomTV 2.0.24 release notes

Skip markers from TheIntroDB now come from its v4 API. TheIntroDB has frozen the v3 API LoomTV used before and plans to retire it, so intro, recap, credits, and preview markers keep loading after that happens. Lookups still use the same TMDB, TVDB, or IMDb IDs, and the markers are unchanged.

Release builds start packaging without waiting for tests and reuse cached Electron and Rust scanner downloads, so new versions publish sooner.
