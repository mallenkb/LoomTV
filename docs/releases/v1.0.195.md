# LoomTV 1.0.195 release notes

LoomTV 1.0.195 adds optional automatic file organization after a library sync.

## Highlights

- Choose Ask me, Automatically, or Off. Ask me remains the default and lets you review changes before applying them.
- Automatic organization waits until scans and playback are idle, and skips files modified within the last 10 minutes.
- Each rename batch can be undone from Library settings.
