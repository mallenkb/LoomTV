# LoomTV 1.0.193 release notes

LoomTV 1.0.193 adds safer library file organization and live TV channel checks to the desktop app.

## Highlights

- Preview and approve movie and episode file renames, move matching sidecars, and undo a completed batch.
- Keep library paths and playback-related records in sync when files move, and recover rename batches interrupted by an app shutdown.
- Verify IPTV streams in the background and list channels only after picture or sound is confirmed; checks pause while media is playing.
- Resolve HLS playlist resources against the provider's redirected URL and preserve subtitle language tags more accurately.
