# LoomTV 1.0.81 Release Notes

LoomTV 1.0.81 improves targeted artwork repair and metadata selection across desktop detail views.

## Highlights

- Apply official metadata candidates to only the poster, cover, or episode data that needs correction.
- Improve artwork repair controls and candidate selection for movies and TV shows.
- Refine metadata API and IPC handling so desktop and renderer behavior stay consistent.
- Update Modern home, settings, movie detail, and TV detail presentation around the new artwork workflow.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop production dependency audit passes.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
