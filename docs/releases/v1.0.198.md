# LoomTV 1.0.198 release notes

LoomTV 1.0.198 adds persistent new-title and episode badges to the desktop library.

## Highlights

- Shows "Newly Added" on recent unwatched titles and "NEW" on unwatched, unstarted episodes.
- Preserves title-added dates across scans and media merges.
- Shares episode update data across library pages and removes the separate "What's New" rail.
- Adds delayed tooltips to sidebar icons and keeps upcoming air-date details on show pages.
