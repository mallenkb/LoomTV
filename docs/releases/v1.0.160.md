# LoomTV 1.0.160 release notes

LoomTV 1.0.160 includes the desktop provider and player-control updates with a server playback fix.

## Highlights

- Cinemeta installs as an optional plugin without manual setup when metadata is online.
- Player and navigation controls keep their frosted blur with darker hover states.
- Compatible recorded media probes are reused, while changed files still trigger a fresh probe.
