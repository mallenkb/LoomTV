# LoomTV 2.0.9 release notes

- Adds original-import inventory, safer title matching, and recoverable file organization and library cleanup.
- Reduces desktop playback memory use with bounded caches, disk-backed thumbnails, and inactive-renderer cleanup.
- Integrates the first local Photos, Music, Audiobooks, Books, and Comics library implementations. These are owner-only desktop libraries; remote access and sharing are not included. Audio format support depends on Chromium, and reading support is limited to EPUB, PDF, and CBZ as appropriate.
- Preserves newer playback, updater, and security fixes while consolidating historical branches. Retired Tauri code is not restored.
- Adds direct HTTPS and bootstrap-secret file configuration to the headless server and fixes shutdown after rejected startup.
- Preserves downloaded media filenames on mobile without weakening cancellation cleanup.

This release publishes Electron desktop installers for macOS, Windows, and Linux. It does not publish Tauri or mobile binaries.
