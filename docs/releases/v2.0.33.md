# LoomTV 2.0.33 release notes

## Playback

- Makes Pill the default control style and keeps Classic available in Appearance settings.
- Adds translucent, blurred control backgrounds, clearer spacing and timeline contrast, and a Settings preview that uses the live episode controls.
- Shows a fixed seek arrow with a second arrow merging into it, alongside an accumulating counter.
- Makes C toggle subtitles and show a brief on-screen hint. Turning captions back on restores the last selected track.
- Fits the playback window to the video's aspect ratio and restores the library window size when playback closes.
- Removes the extra loading wait from local jumps and improves global play/pause while LoomTV is in the background.

## Local library

- Consolidates local video storage while preserving profiles, saved titles, and playback progress.
- Keeps movie cards with no playable source out of the library view.
- Adds Cinemeta confirmation and a fallback that checks a provider match against the local filename and embedded metadata before organizing a movie. Conflicting metadata still blocks automatic changes.
- Fixes organizer database updates and preserves a movie's identity and watch history when its file is renamed or moved.
- Removes the Saved titles group from profile settings.

## Discovery and packaging

- Gives Discover and add-on catalogs shared category navigation and search, with clearer filters.
- Repairs dependency collection for packaged torrent playback and verifies the dependency versions resolved inside the desktop archive.
- Removes an unused vulnerable dependency from the tracker graph and updates Expo tooling to the fixed Zod version with compatibility coverage.
