# LoomTV 1.0.78 Release Notes

LoomTV 1.0.78 fixes the desktop updater dependency used during packaging.

## Highlights

- Include the desktop discovery, pairing, Modern experience, profile, artwork, onboarding, and playback improvements.
- Upgrade `electron-updater` to 6.8.9 so its declared `builder-util-runtime` 9.7.0 dependency matches the patched runtime used by the installers.
- Keep the pnpm 11.17.0 release workflow and scoped production audit.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop production dependency audit passes.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
