# LoomTV 1.0.66 Release Notes

LoomTV 1.0.66 improves paired desktop access to remote libraries.

## Highlights

- Add secure main-process remote-library networking with private-LAN host validation, route allowlisting, request limits, and redirect protection.
- Restore saved pairings across launches and provide clearer recovery when a host pairing expires, is revoked, or needs to be renewed.
- Keep remote credentials out of renderer storage and route remote media, subtitles, thumbnails, and HLS playback through the desktop protocol.
- Improve host-or-remote onboarding, remote profile-aware requests, library refresh, and session disconnect handling.
- Broaden subtitle URL handling for supported non-HTTP schemes and replace broad LAN probing with explicit host discovery or manual entry.

## Verification

- Desktop release CI validates linting, typechecking, tests, installer builds, and packaged runtime dependencies on macOS, Windows, and Linux.
