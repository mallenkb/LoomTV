# LoomTV 2.0.22 release notes

Restores libmpv playback in installed Apple silicon builds by compiling the matching render bridge from source during packaging.

Library cards use smaller cached artwork from providers that do not offer their own renditions. Smaller artwork copies also survive library syncs, reducing repeated downloads and full-size image decoding.

Mac packages carry only the matching FFmpeg, FFprobe and fpcalc architecture, omit unused native build files and the other architecture's native modules, and ship the English Chromium locale.

Desktop releases apply and verify Electron hardening fuses. Browser permissions use an explicit default-deny policy. YouTube and Vimeo links use embedded players, and unsupported video-page links show an error. Native playback fallback attempts each engine once before moving to browser playback.

LibVLC warmup starts two seconds after the first window appears, instead of blocking initial window creation.

This release includes the desktop changes prepared for 2.0.21, which was not published because its dependency-review exception had expired. The existing local node-forge patch and mobile/TV tooling scope were re-reviewed, and the exception now expires on 2026-10-31. The dependency gate remains enabled.

This release publishes Electron desktop installers for macOS, Windows, and Linux. It does not publish Tauri or mobile binaries.
