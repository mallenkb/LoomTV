# LoomTV 1.0.134 Release Notes

LoomTV 1.0.134 adds desktop system media controls and hardens native runtime packaging.

## Highlights

- Adds native system media controls for macOS, Windows, and Linux, including play/pause, seeking, playback rate, and episode navigation.
- Routes controls to the active LibVLC or mpv session without reopening playback or fetching metadata.
- Packages and verifies the platform-specific koffi runtime required by native desktop integrations.
- Includes the verified desktop packages for macOS, Windows, and Linux.
