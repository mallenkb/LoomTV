# LoomTV 2.0.26 release notes

Episodes no longer show "Not added yet" when the file is in your library. Some releases carry an embedded tag with the wrong episode number, such as an episode 2 file tagged as track 1. LoomTV used to trust that tag over the filename, so it stacked two files on one episode and hid the real one. The episode number in the filename now wins.

Files that were filed under the wrong episode move back to the right one on the next library scan.
