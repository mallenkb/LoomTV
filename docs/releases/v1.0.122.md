# LoomTV 1.0.122 Release Notes

LoomTV 1.0.122 improves custom media organization, artwork selection, and desktop release reliability.

## Highlights

- Adds custom media libraries and richer folder organization for content outside Movies, TV Shows, and Anime.
- Expands the artwork chooser into a responsive image grid with provider tags and direct cover or poster actions.
- Improves desktop library cards, navigation, settings, artwork handling, and detail-page controls.
- Keeps custom-folder media separate from the main Movies, TV Shows, and Anime catalogs.
- Fixes Windows release packaging by rebuilding Electron native modules through the cross-platform Node CLI.
