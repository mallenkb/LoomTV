# LoomTV 1.0.121 Release Notes

LoomTV 1.0.121 improves custom video organization, artwork selection, and desktop release preparation.

## Highlights

- Keeps videos from Others folders out of the Movies, TV, and Anime catalogs.
- Labels loose videos from Others as Other video content while preserving playback compatibility.
- Expands and polishes the artwork candidate picker for easier visual comparison.
- Improves desktop native dependency preparation and metadata refresh reliability.
