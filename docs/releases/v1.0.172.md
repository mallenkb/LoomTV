# LoomTV 1.0.172 release notes

LoomTV 1.0.172 hardens the Electron desktop app and its release process.

## Highlights

- Adds cross-platform validation, signed artifact checks, trusted attestations, checksums, and release-asset verification.
- Tightens automatic update publisher checks and macOS update staging and rollback.
- Reduces memory pressure while loading large libraries and improves playback, profile, and progress lifecycles.
- Adds server setup, API, container, and plugin protocol hardening.
