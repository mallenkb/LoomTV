# LoomTV 1.0.62 Desktop Release Notes

LoomTV 1.0.62 adds a first-run desktop setup choice and improves end-of-episode skip markers.

## Highlights

- Choose whether a desktop starts a local library or connects to an existing LoomTV host.
- Discover hosts on the local network or connect manually with an address and six-digit pairing PIN.
- Use remote profiles, library data, progress, playback preferences, streams, transcoding, and skip markers from the paired host.
- Refresh remote credentials automatically and refresh the shared library every 30 seconds.
- Limit remote desktops to personal settings while keeping host administration on the host computer.
- Separate anime or episode endings as **Outro** markers instead of treating them as production Credits.
- Show distinct Outro, Credits, and Preview prompts with overlap priority and independent settings.
- Migrate existing AniSkip ending markers and invalidate stale marker cache entries safely.
- Bound fallback host discovery to avoid long Windows network scans.

## Verification

- Desktop ESLint and renderer/main TypeScript checks pass with zero errors and warnings.
- Tagged GitHub Actions runs the complete desktop test suite and packages macOS, Windows, and Linux installers.
