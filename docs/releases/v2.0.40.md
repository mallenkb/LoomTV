# LoomTV 2.0.40 release notes

## Startup

- Show the saved library before starting the local administration server on existing installations.
- Load native libmpv libraries on demand so startup diagnostics do not block the main thread.
- Load profile preferences, saved lists, and playback progress together.

## Memory and window recovery

- Trim renderer caches only after the desktop window is hidden, and cancel a pending trim when the user returns.
- Refresh transparent window contents after wake, unlock, or restore.

## Playback and search

- Keep native player control backdrops aligned with the top controls.
- Simplify the library filter menu and refine its sizing and focus targets.
- Use a refresh icon for metadata update actions.
