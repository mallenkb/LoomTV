# LoomTV 1.0.87 Release Notes

LoomTV 1.0.87 improves next-episode playback from preview skip prompts.

## Highlights

- Find the next episode by season and episode number before falling back to file-path matching.
- Let the preview skip prompt immediately complete the current episode and start the next one.
- Keep next-episode navigation reliable for normalized and stream-based playback URLs.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop production dependency audit passes.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
