# LoomTV 1.0.31

This release tightens fullscreen playback behavior.

## Updates

- Fixes the fullscreen Back button so it uses the normal back action instead of only exiting fullscreen.
- Keeps the standard bottom playback control layout in fullscreen.
- Moves the fullscreen video image up with a 24px top offset.
- Keeps the fullscreen top chrome controls at a 24px top inset.
