# LoomTV 1.0.90 Release Notes

LoomTV 1.0.90 improves playback stability and OpenSubtitles controls in the desktop app.

## Highlights

- Keep browser-stream seeking and audio/subtitle track changes stable when playback uses remuxed streams.
- Prefer dialogue subtitles over signs-only tracks when selecting a default subtitle.
- Start bitmap subtitle burn-in after the fast stream is playable, reducing startup delay.
- Pause OpenSubtitles downloads when its daily quota is reached and immediately honor disabling downloads during a library scan.
- Clarify OpenSubtitles settings and make enabling or disabling downloads persist immediately.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop production dependency audit passes.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
