# LoomTV 1.0.141 Release Notes

LoomTV 1.0.141 improves startup readiness, Live TV source management, and desktop metadata loading.

## Highlights

- Lets the desktop shell finish loading without waiting on optional LibVLC or artwork probes.
- Improves Live TV source settings and sidebar source caching.
- Fixes Node-based desktop metadata tests by using explicit TypeScript module extensions.
- Includes verified desktop packages for macOS, Windows, and Linux.
