# LoomTV 1.0.173 release notes

LoomTV 1.0.173 improves native playback in the Electron desktop app.

## Highlights

- Improves native seek responsiveness for LibVLC and libmpv playback.
- Makes local playback engine selection platform-aware.
- Reduces playback-related memory pressure and defers library synchronization while playback is active.
- Improves native playback lifecycle handling and warmup behavior.
