# LoomTV 1.0.53 Release Notes

LoomTV 1.0.53 refreshes the desktop app identity and improves playback, local access, and release behavior.

## Changed

- Restores the LoomTV product name across desktop packaging, windows, menus, settings, and network surfaces.
- Refreshes desktop themes, navigation, library controls, cards, dialogs, and settings presentation.
- Adds safer authenticated browser-renderer routes for local development and recovery.
- Simplifies LAN pairing around a six-digit PIN and improves local-device discovery messaging.
- Improves subtitle styling, artwork handling, update behavior, and packaged runtime validation.
- Refines playback time controls and advances reliably after intermittent end-of-playback resets.

## Verification

- `git diff --check` passes locally.
- Tagged GitHub Actions will run desktop lint, typecheck, tests, packaging, and packaged runtime verification for Windows, macOS, and Linux.
- Mobile working-tree changes are intentionally excluded from this desktop release commit.
