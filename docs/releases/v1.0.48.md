# Loom Media Server 1.0.48 Release Notes

Loom Media Server 1.0.48 improves desktop skip-analysis reliability and responsiveness.

## Changed

- Drains eligible analysis work efficiently while respecting idle, AC-power, and active-playback safeguards.
- Starts manual scans promptly, supports quick/full scan modes, and keeps manual work from being buried behind background jobs.
- Adds clearer analysis phases, manual-job counts, waiting counts, and library coverage status.
- Improves cancellation, recovery, database reconciliation, and playback-triggered analysis interruption.
- Adds focused analysis coordinator, batching, and specialized repository coverage.

## Verification

- `git diff --check` passes locally.
- Tagged GitHub Actions will run desktop lint, typecheck, tests, packaging, and packaged runtime verification for Windows, macOS, and Linux.
- Local lint/typecheck could not complete because the npm registry was unavailable while restoring dependencies.
