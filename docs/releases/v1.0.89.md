# LoomTV 1.0.89 Release Notes

LoomTV 1.0.89 fixes audio and subtitle track selection during playback.

## Fixes

- Keep the selected audio or subtitle track active while LoomTV prepares and swaps in the replacement stream.
- Stop live preference changes from rerunning episode track initialization and reverting the selection to the old track or `Off`.
- Treat selected external subtitle tracks as enabled so they render immediately and remain enabled across episode changes.
- Preserve saved per-title and profile defaults for future playback sessions.

## Release validation

- Workspace linting and TypeScript checks pass locally.
- GitHub release CI runs workspace tests and builds installers for macOS, Windows, and Linux.
