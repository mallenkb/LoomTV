# LoomTV 1.0.189 release notes

LoomTV 1.0.189 improves Electron memory handling and local playback startup on macOS.

## Highlights

- Trims unused playback probes, artwork cache, and stale library snapshots while preserving active playback and recent navigation state.
- Rebuilds LibVLC's plugin cache after signing ad-hoc macOS builds, restoring lazy plugin loading and reducing startup overhead.
- Keeps release publication gated on the exact validated commit and stable release identity.
