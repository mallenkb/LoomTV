# LoomTV 1.0.187 release notes

LoomTV 1.0.187 improves desktop playback reliability and keeps artwork and library work responsive while media is playing.

## Highlights

- Preserves volume and mute intent across native-engine fallback and playback transitions.
- Improves native decoder diagnostics, pause state handling, and episode title hydration.
- Suspends nonessential artwork work during playback and bounds concurrent artwork decoding.
- Hardens artwork retry and admission handling and improves library scan reconciliation.
- Improves player accessibility labels and keyboard behavior.
