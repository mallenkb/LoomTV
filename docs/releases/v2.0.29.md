# LoomTV 2.0.29 release notes

LoomTV now runs on Electron 44, and the Mac app is 43 MB smaller. The app bundle used to carry copies of interface libraries that were already built into the app, including the video, icon and animation libraries. Those copies are gone, and the database module now ships only the build for your computer.

Playback also lets go of a few images it used to hold on to. Seek-bar previews that finish loading after you close the player are released right away, and so are pause-screen logos from the previous title. When LoomTV clears unused images after sitting in the background, it no longer does so in the seconds after you come back to it.
