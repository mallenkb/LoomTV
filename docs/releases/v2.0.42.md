# LoomTV 2.0.42 release notes

## Episode list

- Show each episode's runtime in the player panel when it is available from the library or playback history.
- Read the runtime from the file for nearby episodes whose saved metadata has no duration.

## Library scanning

- Use the same scan and catalog refresh path at startup and from the manual scan buttons.
- Retry an incomplete quick scan with a full scan of the affected folder before retaining its old entries.
- Return the updated library when a scan finishes without waiting for artwork caching. Report a scan that could not save its result.

## Dependencies

- Update Expo's transitive file matching and certificate tools to versions that address the current production audit findings.
- Use npm-hosted platform binaries for the server's WebRTC dependency so clean installs do not depend on an older release binary.
