# LoomTV 1.0.95 Release Notes

LoomTV 1.0.95 simplifies desktop navigation feedback.

## Highlights

- Keep the active modern sidebar icon fixed instead of sliding a fluid highlight between icons.
- Keep the active Settings tab fixed and prevent hover highlights from changing inactive tab contrast.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
