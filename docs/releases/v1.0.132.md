# LoomTV 1.0.132 Release Notes

LoomTV 1.0.132 fixes the desktop player state after native playback ends.

## Highlights

- Restores the normal renderer layer when native playback reaches the end of a video.
- Clears the native playback surface cleanly after completion.
- Lets users press Play to restart a completed item.
- Includes the verified desktop packages for macOS, Windows, and Linux.
