# LoomTV 1.0.136 Release Notes

LoomTV 1.0.136 improves desktop Live TV setup and production startup safety.

## Highlights

- Adds selectable icons for Live TV source tabs, with saved choices and migration support.
- Keeps desktop development renderer connections on the intended loopback address and prevents production builds from using a development URL.
- Adds built-app launch and production-main verification checks.
- Includes the verified desktop packages for macOS, Windows, and Linux.
