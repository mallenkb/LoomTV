# LoomTV 1.0.30

This release adds focused quality-of-life controls for fixing local library metadata and browsing active collections.

## Updates

- Adds a clearer Fix Match flow on movie, TV, and anime detail pages for choosing the correct metadata provider result.
- Adds item-level metadata refresh so a single title can be updated without rescanning the full library.
- Adds Movies, TV Shows, and Anime filters for all, in-progress, unwatched, watched, missing metadata, and missing artwork.
- Improves Continue Watching so TV and anime point to exact active episodes and can suggest the next unwatched episode.
- Fixes anime episode rating merging so Jikan scores can fill provider gaps while keeping TVmaze/TMDB episode titles and dates.
- Shows episode ratings in the player episode drawer and improves vertical alignment in episode rows.
