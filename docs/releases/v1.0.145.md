# LoomTV 1.0.145 Release Notes

LoomTV 1.0.145 improves playback reliability and keeps library, server, and client behavior aligned across the supported apps.

## Highlights

- Stabilizes playback progress updates and native LibVLC metadata handling.
- Improves library mutations, custom-folder support, and desktop server administration.
- Cleans up media-server and plugin/catalog integration paths.
- Updates shared mobile playback presentation and public catalog contracts.
- Publishes refreshed macOS, Windows, and Linux installers with updater manifests.
