# LoomTV 1.0.15

LoomTV 1.0.15 focuses on making local playback feel more like a normal media player, tightening series handoff behavior, and improving the About/update experience.

## Playback

- Adds MPV-first local playback for files the browser cannot direct-play, reducing unnecessary browser buffering for local media.
- Improves HLS fallback stability by waiting briefly for pending local segments instead of returning immediate 404s.
- Keeps short skip actions instant for transcoded playback when the target is already inside the active stream window.
- Changes default seek controls to 10 seconds back and 15 seconds forward.
- Adds Playback settings for customizing the back/forward skip durations.
- Prevents manual pause from being overridden by later ready/buffer events.
- Cancels stale loads, HLS sessions, MPV sessions, and next-episode timers when the player closes.
- Guards episode switching so stale autoplay cannot jump to media outside the currently open series.
- Forces clean player remounts per media file to avoid state bleeding between titles.

## Series

- Adds an unobtrusive Up Next prompt near the end of episodes without blurring the video.
- Marks near-end completions more reliably so the next episode can appear or autoplay after completion.
- Keeps the player from freezing near the end of transcoded series episodes when the end position is reached.

## Subtitles

- Adds subtitle text, outline, background, size, and position controls.
- Applies native subtitle size/position changes without reloading the player.
- Adds an explicit Apply action for burned-in subtitle style changes so slider edits do not repeatedly restart local streams.

## Updates And About

- Adds immediate update-check feedback with a visible loader while contacting GitHub releases.
- Shows the real app version in the About badge during browser/dev runs instead of `vdev`.
- Lets browser/dev update checks fetch the latest GitHub release status for clearer testing.

## Library And Docs

- Adds clearer empty-state actions for Movies, TV Shows, and Anime folders.
- Updates README screenshots and adds Settings screenshots for library, network, theme, and About screens.
