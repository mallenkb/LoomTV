# LoomTV 1.0.150 release notes

LoomTV 1.0.150 updates the Electron desktop app with the latest playback, subtitle, settings, and application-structure changes from `main`.

## Highlights

- Adds the latest Electron playback and native runtime updates.
- Updates subtitle controls and desktop settings screens.
- Removes obsolete application code and publishes refreshed macOS, Windows, and Linux installers with updater manifests.
