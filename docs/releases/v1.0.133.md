# LoomTV 1.0.133 Release Notes

LoomTV 1.0.133 updates desktop playback controls and subtitle placement.

## Highlights

- Replaces the large Up Next modal with a compact Next Episode button that appears 20 seconds before the episode ends and fills until completion.
- Keeps the button and subtitles clear of the timeline as player controls appear and disappear.
- Removes the obsolete next-episode countdown and scrubbing state.
- Includes the verified desktop packages for macOS, Windows, and Linux.
