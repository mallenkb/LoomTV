# LoomTV 1.0.167 release notes

LoomTV 1.0.167 improves desktop library scanning, artwork handling, and playback.

## Highlights

- Adds a bundled scanner for faster checks on eligible unchanged quick scans while keeping TypeScript as the default for full discovery.
- Reduces unnecessary catalog and artwork data retention during library browsing and scans.
- Uses an animated download icon while an app update is downloading.
