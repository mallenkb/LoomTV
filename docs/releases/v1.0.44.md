# Loom Media Server 1.0.44 Release Notes

Loom Media Server 1.0.44 fixes skip-marker provider timeout handling in desktop builds.

## Fixed

- Keeps provider timeout timers alive long enough for aborted requests to resolve cleanly.
- Prevents pending provider requests from cancelling the remaining desktop test suite or blocking playback recovery.

## Verification

- Desktop lint and typecheck pass locally.
- Tagged GitHub Actions will run desktop tests, packaging, and packaged runtime verification for Windows, macOS, and Linux.
- Local tests were not run per repository instructions.
