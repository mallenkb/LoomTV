# Loom Media Server 1.0.52 Release Notes

Loom Media Server 1.0.52 fixes macOS launch failure in release builds without a configured Developer ID certificate.

## Fixed

- Consistently ad-hoc signs the complete macOS app bundle before ZIP and DMG creation when Developer ID signing is unavailable.
- Removes hardened runtime from ad-hoc fallback bundles so dyld does not reject Electron Framework for a Team-ID mismatch.
- Verifies packaged macOS Team IDs and hardened-runtime state before release artifacts are uploaded.

## Verification

- `git diff --check` and focused script syntax checks pass locally.
- Tagged GitHub Actions will run desktop lint, typecheck, tests, packaging, packaged runtime verification, and artifact upload for Windows, macOS, and Linux.
