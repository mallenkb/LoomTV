# LoomTV 1.0.174 release notes

LoomTV 1.0.174 fixes the macOS update migration path for legacy ad-hoc installations.

## Highlights

- Allows a legacy ad-hoc LoomTV installation to upgrade in place to a verified Developer ID-signed release.
- Keeps already signed installations pinned to their existing Apple Team ID.
- Requires the updater SHA-512 check, the exact LoomTV bundle identifier, a valid Developer ID Application signature, and Gatekeeper/notarization approval before a legacy bootstrap can install.
- Preserves the existing rollback-safe macOS replacement flow and service shutdown behavior.
