# LoomTV 1.0.131 Release Notes

LoomTV 1.0.131 fixes native desktop playback track handling.

## Highlights

- Keeps LibVLC track IDs separate from the stable stream indexes used by the player UI.
- Lets users change LibVLC audio and subtitle tracks without switching playback engines.
- Refreshes native track state after track changes and reports failed changes to the player.
- Keeps subtitle cues aligned with the playback clock and clears saved subtitle offsets.
- Includes the verified desktop packages for macOS, Windows, and Linux.
