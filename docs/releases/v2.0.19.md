# LoomTV 2.0.19 release notes

Adds live subtitle appearance presets with adjustable soft and solid backgrounds, tighter line spacing, and native blur for the soft style. Simplifies the media sidebar while keeping Others available, shows approved catalog add-ons as navigation destinations, and removes bundled providers from the removable add-on list.

This release publishes Electron desktop installers for macOS, Windows, and Linux. It does not publish Tauri or mobile binaries.
