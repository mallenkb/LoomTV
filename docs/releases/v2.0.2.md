# LoomTV 2.0.2 release notes

LoomTV 2.0.2 adds a subtitle shortcut, avoids a redundant LibVLC subtitle toggle, and updates the workspace to pnpm 12.6.0.

## Highlights

- Press C to enable the first available subtitle track, or open subtitle controls when no track is available or selection fails.
- Treat subtitles that are already off as a successful no-op in LibVLC.
- Use pnpm 12.6.0 in the workspace and pinned CI workflows.
