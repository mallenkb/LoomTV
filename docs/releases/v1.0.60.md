# LoomTV 1.0.60 Desktop Release Notes

LoomTV 1.0.60 is the corrected desktop publication of the complete profile release documented in [the detailed LoomTV 1.0.59 feature inventory](v1.0.59.md).

## Included

- Full profile selection, management, ordering, locking, automatic sign-in, avatar upload, export, and import.
- Four-digit profile PIN setup, entry, removal, and Owner recovery.
- Kids profiles with country-specific age ratings, unrated-content policy, and library-folder access controls.
- Profile-filtered desktop and LAN libraries, media paths, artwork, subtitles, direct streams, transcoding, and HLS sessions.
- Per-profile progress, playback track choices, theme, navigation, skip intervals, Watchlist, and Favorites.
- Home Watchlist and Favorites rails plus list controls on movie, television, and anime detail pages.
- Profile-aware LAN APIs, capabilities, signed resource identity, selection revisions, and stale-write rejection.
- TMDB, OMDb, and Jikan content-rating ingestion and conservative cross-provider rating merges.
- Owner-only server, metadata, artwork, analysis, database, and library administration.
- DiceBear Glyphs avatars, custom profile images, migrations, attribution, and packaged licensing.
- The full additions, behavior changes, removals, migrations, security details, and packaging changes listed in the 1.0.59 inventory.

## Fixed since 1.0.59

- Updates the Settings deferred-probe source test to recognize the new active-profile dependency array.
- Updates the macOS no-drag tab-strip test to recognize role-filtered `sections.map` rendering.
- Makes no application behavior change beyond the desktop implementation already described in the detailed inventory.

## Verification

- Desktop ESLint and renderer/main TypeScript checks pass locally with zero errors and zero warnings.
- Tagged GitHub Actions runs all desktop tests and builds, verifies, and uploads macOS, Windows, and Linux installers.
