# Loom Media Server 1.0.12 Release Notes

Loom Media Server 1.0.12 improves update reliability, release delivery, and the in-app update experience.

## Fixed

- Added explicit GitHub check/install controls with a startup update check and periodic background checks.
- Added a menu-driven update path: `Check for Updates…` and `Install Update…`.
- Reworked downloaded-update handling to prompt for restart and avoid auto-quit surprises.
- Improved update state propagation to renderer and to the side menu UX.
- Added a compact, theme-aware sidebar update affordance that appears only while downloading or when an update is ready.
- Switched release packaging to Electron Builder so GitHub releases include `latest*.yml` update metadata and blockmaps for `electron-updater`.
- Added safer release signing hooks and tag-based release naming consistency.
- Fixes CI signing fallback behavior when production signing secrets are not configured.
- Adds Linux package maintainer metadata for DEB/RPM release builds.
- Bumped release version to `1.0.12`.

## Changed

- Update and release flow now publishes Electron Builder artifacts from CI so `electron-updater` can reliably resolve package downloads and deltas.
- Electron Forge remains the local development runner; Electron Builder owns production release artifacts.
