# Loom Media Server 1.0.13

## Fixes

- Fixes macOS launches that appeared to do nothing when Loom Media Server was already running in the background.
- Adds a single-instance lock so opening Loom Media Server again brings the existing window forward instead of starting another copy.
- Keeps the macOS app lifecycle healthy after closing all windows, so Dock activation restores Loom Media Server cleanly.
