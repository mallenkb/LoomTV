# Loom Media Server 1.0.46 Release Notes

Loom Media Server 1.0.46 hardens desktop library scanning and item preservation.

## Fixed

- Prevents overlapping manual, startup, and automatic library scans.
- Deduplicates scan results across folders and resolves cached items by normalized path.
- Makes full scans refresh filesystem-derived episode data instead of retaining stale probes or subtitle lists.
- Preserves user-facing metadata only for seasons and items that still exist in the fresh scan.
- Keeps folder-kind classification and local titles stable during scan recovery.

## Verification

- Desktop lint and typecheck pass locally.
- Tagged GitHub Actions will run desktop tests, packaging, and packaged runtime verification for Windows, macOS, and Linux.
- Local tests were not run per repository instructions.
