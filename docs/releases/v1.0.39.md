# Loom Media Server 1.0.39 Release Notes

Loom Media Server 1.0.39 refreshes the desktop navigation and library/settings presentation, with matching icon updates in the mobile surface.

## Changed

- Adds the refreshed Loom icon set for search, filtering, navigation, playback, and settings.
- Uses filled active-state navigation icons and hides empty library sections from navigation.
- Increases poster sizing for a more readable desktop library grid.
- Refines settings panel styling and settings navigation behavior.

## Verification

- GitHub Actions will run the desktop lint, typecheck, test, packaging, and packaged-runtime checks for the tagged release.
- Local tests were not run per repository instructions.
