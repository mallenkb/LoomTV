# LoomTV 1.0.72 Release Notes

LoomTV 1.0.72 republishes the modern desktop experience and corrects the desktop release pipeline.

## Highlights

- Add the optional Modern cinematic home, refreshed navigation, full-library search, and modern detail pages introduced in 1.0.71.
- Keep Default and Modern layout choices profile-aware across local and paired clients.
- Retain cleaner update status controls without visual progress bars.
- Scope production dependency auditing to the desktop app so mobile-only Expo advisories cannot block desktop installer releases.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
