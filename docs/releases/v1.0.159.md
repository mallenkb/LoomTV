# LoomTV 1.0.159 release notes

LoomTV 1.0.159 adds automatic Cinemeta setup for desktop users and refines the player controls.

## Highlights

- Cinemeta installs as an optional plugin without manual setup when metadata is online.
- Player and navigation controls keep their frosted blur with darker hover states.
- The legacy OpenSubtitles API setup is removed in favor of the built-in plugin flow.
