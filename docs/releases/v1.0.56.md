# LoomTV 1.0.56 Release Notes

LoomTV 1.0.56 adds viewer profiles to the desktop app and keeps each viewer's playback activity separate.

## Added

- Adds profile creation, editing, deletion, avatar selection, and a Who's Watching gate for multi-profile libraries.
- Adds optional profile PIN protection and profile switching from the desktop sidebar.
- Stores profile state and progress through new database migrations, repositories, IPC contracts, and local network protocol support.

## Improved

- Keeps Continue Watching and playback progress isolated to the active profile.
- Flushes pending progress updates during playback handoffs and prevents stale writes from leaking across profile switches.
- Improves artwork fallback handling, media probing, library search, and desktop playback lifecycle behavior.

## Verification

- Tagged GitHub Actions validates desktop lint, typechecking, tests, packaging, packaged runtime dependencies, and artifact upload on macOS, Windows, and Linux.
