# LoomTV 1.0.74 Release Notes

LoomTV 1.0.74 improves saved playback track preferences.

## Highlights

- Preserve a quick audio or subtitle selection while saved preferences are still loading.
- Serialize preference saves so rapid track changes do not overwrite one another.
- Match saved tracks by language, title, and codec before falling back to episode-local stream indexes.
- Remount the player reliably when switching between file-based playback items.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
