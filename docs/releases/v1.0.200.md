# LoomTV 1.0.200 release notes

LoomTV 1.0.200 adjusts sidebar update and library refresh controls to match the profile avatar image size.

## Highlights

- Matches modern sidebar update and refresh indicators to the 36 px profile avatar image.
- Matches classic sidebar update and refresh buttons to the 24 px profile avatar image.
- Adds a smooth theme-aware hover transition to the modern update button.
