# LoomTV 1.0.29

This release reduces background artwork cache growth and playback-time resource spikes.

## Updates

- Bounds the number of artwork fallback URLs LoomTV caches for each library item.
- Uses smaller TMDB logo images instead of original-size logo PNGs.
- Prunes stale artwork cache rows during artwork caching.
- Avoids duplicating SQLite-cached artwork into Chromium's HTTP cache.
- Stops playback-logo lookup from synchronously caching the whole library when a logo already exists.
