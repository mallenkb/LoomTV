# LoomTV 1.0.126 Release Notes

LoomTV 1.0.126 refreshes the verified desktop packages for macOS, Windows, and Linux while correcting the repository's mobile release-gate security configuration.

## Highlights

- Pins every mobile release-gate action to an immutable commit SHA.
- Restricts the pull-request workflow to read-only repository access.
- Prevents checkout credentials from persisting while untrusted pull-request code runs.
- Includes the browser-host, artwork routing, custom-folder navigation, and desktop presentation fixes from LoomTV 1.0.125.
