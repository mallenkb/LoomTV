# Loom Media Server 1.0.37 Release Notes

Loom Media Server 1.0.37 is a desktop release focused on the refreshed app architecture and a more reliable packaged experience.

## Highlights

- Ships the reorganized desktop app under `apps/desktop`.
- Refreshes library browsing, playback, settings, themes, metadata, and LAN sharing flows.
- Includes Electron Builder packaging for macOS, Windows, and Linux with bundled FFmpeg/FFprobe resources.
- Adds packaged-runtime verification and keeps desktop auto-update metadata aligned with GitHub Releases.

## Changed

- Bumped the desktop app version to `1.0.37`.
