# LoomTV 2.0.17 release notes

- Sets the next-episode calendar card's right padding to 20 pixels, giving the countdown more space from the edge. Left, top, and bottom padding remain matched at 8.8 pixels.

Includes the compact calendar card and all updates from 2.0.16.

This release publishes Electron desktop installers for macOS, Windows, and Linux. It does not publish Tauri or mobile binaries.
