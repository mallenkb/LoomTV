# LoomTV 1.0.10 Release Notes

LoomTV 1.0.10 fixes app update delivery on macOS and Windows installers.

## Fixed

- Reworked update checks to use `electron-updater` with GitHub provider config.
- Restored reliable periodic and startup update checks in packaged builds.
- Made update download progress visible in-app and kept auto-install flow from timing out.
- Updated release publishing defaults so non-draft releases are emitted for updater compatibility.

## Changed

- Bumped app version to `1.0.10`.
