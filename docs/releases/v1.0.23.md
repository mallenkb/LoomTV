# LoomTV 1.0.23

This release exists to validate the macOS updater fallback introduced in 1.0.22.

## Updates

- Publishes a fresh macOS zip so LoomTV 1.0.22 can exercise the fallback updater path end to end.
- Keeps renderer asset paths relative after install so the relaunched app does not show a blank window.

## Verification

- Used to test that restart-to-update closes LoomTV, replaces `/Applications/LoomTV.app`, relaunches the app, and loads the 1.0.23 UI.
