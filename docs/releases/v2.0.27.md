# LoomTV 2.0.27 release notes

This release includes the fix from 2.0.26, which was tagged but never published.

Episodes no longer show "Not added yet" when the file is in your library. Some releases carry an embedded tag with the wrong episode number, such as an episode 2 file tagged as track 1. LoomTV used to trust that tag over the filename, so it stacked two files on one episode and hid the real one. The episode number in the filename now wins.

The first library scan after updating re-reads every folder once, so files that were filed under the wrong episode move back to the right one, even with a quick scan.

The profile menu has Full scan again, under Quick scan. A quick scan only rebuilds folders whose files changed; a full scan re-reads every file.
