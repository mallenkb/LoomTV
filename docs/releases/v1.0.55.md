# LoomTV 1.0.55 Release Notes

LoomTV 1.0.55 restores independent desktop release validation.

## Fixed

- Removes mobile typecheck and tests from the desktop installer workflow.
- Keeps desktop releases gated by desktop lint, typecheck, tests, packaging, packaged runtime verification, and artifact upload on macOS, Windows, and Linux.

## Verification

- The preceding release run passed all 170 desktop tests before being blocked by unrelated mobile-only assertions.
- Tagged GitHub Actions will validate and package only the desktop application surfaces required for this release.
