# LoomTV 2.0.43 release notes

If SQLite detects damage in your library at startup, LoomTV now offers to restore a saved database. Choose your latest LoomTV database backup, or select the dated migration backup if one is available.

The restore uses the profiles, settings, and playback history saved in that backup. LoomTV checks the backup, saves the damaged database separately, and shows you where it kept the copy. Devices need to pair again after recovery.

The desktop app and its built-in server now open the library through the same SQLite library so their connections coordinate file locks.
