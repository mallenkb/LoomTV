# LoomTV 1.0.84 Release Notes

LoomTV 1.0.84 fixes the Modern detail hero in the desktop app.

## Highlights

- Render movie, TV, and anime hero backdrops full-width inside Electron instead of constraining them to a partial-width frame.
- Keep the existing web hero layout unchanged.
- Match the Modern player skip prompt to the rounded control style.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
