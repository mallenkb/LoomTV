# LoomTV 1.0.129 Release Notes

LoomTV 1.0.129 refines the desktop experience and makes the browser renderer responsive across phone and tablet layouts.

## Highlights

- Adds responsive browser navigation, safe-area spacing, mobile search content, and touch-friendly media rails.
- Improves hero artwork fallbacks, metadata layout, action controls, slide indicators, and responsive sizing.
- Refines detail-page transitions and back navigation, including reliable history fallback behavior.
- Keeps Electron desktop windows within a readable minimum size while scoping mobile layout behavior to the browser renderer.
- Refreshes verified desktop packages for macOS, Windows, and Linux.
