# LoomTV 1.0.67 Release Notes

LoomTV 1.0.67 refines the desktop profile and remote-library experience.

## Highlights

- Improve remote profile synchronization and playback progress handling for paired libraries.
- Improve recovery and seeking for remote streams that do not expose a seekable range.
- Refine host-or-remote onboarding layout, branding, profile setup, and switching flow.
- Keep Continue Watching dismissals separate per profile and persist them across launches.
- Prevent the library poster grid from being obscured by the now-playing bar.

## Verification

- Desktop release CI validates linting, typechecking, tests, installer builds, and packaged runtime dependencies on macOS, Windows, and Linux.
