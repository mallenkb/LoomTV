# LoomTV 1.0.94 Release Notes

LoomTV 1.0.94 refines the desktop hero actions.

- Use a solid play icon for the blue Play and Resume actions on movie and TV detail pages.

- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
