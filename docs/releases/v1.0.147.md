# LoomTV 1.0.147 Release Notes

LoomTV 1.0.147 improves playback diagnostics, download reliability, and cross-client progress handling.

## Highlights

- Adds clearer desktop playback diagnostics and improves LibVLC startup and window readiness.
- Makes mobile download replacement safer and validates completed download sizes.
- Improves server catalog state handling and TV playback progress across direct and HLS sessions.
- Publishes refreshed macOS, Windows, and Linux installers with updater manifests.
