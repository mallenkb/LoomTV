# LoomTV 1.0.20

LoomTV 1.0.20 is a hotfix for packaged startup and release verification.

## Updates

- Includes `electron-updater` and its runtime dependencies in Forge-packaged builds so the main process can start cleanly.
- Extends packaged runtime verification so missing updater dependencies are caught before release.
- Keeps packaged renderer asset paths relative for file-based app loading.

## Cleanup

- Removes unused default React imports left over from the automatic JSX runtime migration.
- Removes redundant Knip configuration entries.

## Verification

- Confirms the packaged macOS app launches without the missing `electron-updater` startup error.
