# Loom Media Server 1.0.8 Release Notes

Loom Media Server 1.0.8 fixes the installed-app folder picker regression from the 1.0.7 package.

## Fixed

- Fixed installed macOS builds crashing when adding library folders.
- Rebuilt `better-sqlite3` for Electron before packaging so the packaged native module matches Electron's Node ABI.
- Extended the packaged runtime verification to fail when the bundled SQLite native module cannot be loaded by Electron.

## Changed

- Bumped the app version to `1.0.8`.
