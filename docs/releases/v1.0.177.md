# LoomTV 1.0.177

## Playback changes

- Fix VideoToolbox initialization for eligible 4K HEVC files on Apple Silicon, avoiding software decoding when parameter sets arrive in the video packets.
- Show a thumbnail and timestamp when hovering over or dragging the timeline. Preview images use a bounded cache and nearby keyframes.
- Remove bottom padding beneath the player controls and reduce the space above them.

Idle behavior, the engine order, and 1080p/2K decoder behavior remain on the 1.0.176 path. The 4K native decoder patch applies only to Apple Silicon macOS. Windows and Linux playback remain unchanged.

The broader playback and artwork changes are preserved on the `codex/future-playback-improvements-20260919` branch. See [the saved work index](../../future-updates/playback-improvements-2026-09-19.md).
