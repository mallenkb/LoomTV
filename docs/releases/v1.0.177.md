# LoomTV 1.0.177 release notes

LoomTV 1.0.177 improves native playback in the Electron desktop app.

## Highlights

- Adds native playback bridge checks and updates packaged runtime staging for supported desktop targets.
- Improves native engine startup verification, fallback handling, track selection, and lifecycle cleanup.
- Adds seek hover previews and keeps subtitles clear of the player controls.
- Hardens playback IPC, cache updates, and Linux LibVLC compatibility.
- Keeps the browser playback fallback available where no reviewed native payload is bundled.
- Reduces repeated artwork hashing and keeps audio and subtitle decoders available during native playback.
- Suspends background artwork decoding while a video is playing.
