# LoomTV 1.0.98 Release Notes

LoomTV 1.0.98 brings custom folders into the shared modern library experience.

## Highlights

- Add an Others category to the modern navigation when custom folders are configured.
- Include Others in the compact navigation layouts so custom-folder access stays consistent across app surfaces.
- Add the same search and library-health filters to the custom-folder page used by Home and the standard libraries.
- Keep custom-folder empty and no-match states aligned with the rest of the modern library pages.

## Verification

- Desktop ESLint and TypeScript checks pass.
- Desktop release CI validates tests, installer builds, packaged runtime dependencies, and update artifacts on macOS, Windows, and Linux.
