# LoomTV 1.0.57 Release Notes

LoomTV 1.0.57 republishes the desktop viewer-profile release with corrected profile-service type contracts.

## Fixed

- Passes the optional guest device identifier through the database profile-list wrapper.
- Narrows editable profile types so temporary guest profiles cannot enter the owner, standard, or kids update path.
- Restores desktop typechecking and installer generation on macOS, Windows, and Linux.

## Included

- Viewer profile creation, editing, deletion, avatars, profile switching, and optional PIN protection.
- Profile-specific Continue Watching history and playback progress.
- Safer progress flushing and playback handoffs when switching viewers.

## Verification

- Tagged GitHub Actions validates desktop lint, typechecking, tests, packaging, packaged runtime dependencies, and artifact upload on macOS, Windows, and Linux.
