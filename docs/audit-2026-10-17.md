## Findings

### F1 — Lint scans `.claude` worktrees (low)
`eslint.config.mjs` ignores do not include `.claude/**`, so `pnpm lint` reports duplicate warnings from worktree copies. Add `'**/.claude/**'` to ignores.

### F2 — Duplicate cinemeta import in main.ts (low)
`apps/desktop/src/main.ts:125,336` import the same module twice. Consolidate imports.

### F3 — Knip dead code (low)
24 unused exports and 10 unused types across desktop src. Examples: `LIBRARY_KINDS`, `libraryTypeDefinition`, `supportsAddonResource`, `collectObsoleteData`, `StremioManifestLinkError`. Remove or mark internal. Duplicate export `QUIET_MS|STABLE_CHECK_MS` in `fileSettling.ts`.

### F4 — Unused binary ignores in knip config (cosmetic)
knip flags 10 binaries (`file`, `which`, etc.) as no longer referenced by ignoreBinaries; remove them.

### F5 — Dev dependency vulnerabilities (informational)
66 advisories, all in dev/build tooling (vite-plus/tinypool, electron, undici via @electron/get, node-gyp). None ship in production; production audit gate is clean. Track Electron advisory GHSA-9qh4 (webview Node integration) — requires Electron ≥43.4.1; upgrade when available.

### F6 — Performance backlog unaddressed (medium)
All 8 items in `docs/performance-and-memory-issues.md` remain open: no CI perf/memory regression gate, LibVLC 16ms state spam while paused, no startup timing marks, no V8 compile cache, possible missing renderer code cache, blank window during React load, wasted hover prefetch, unexplained ~600MB idle / ~900MB HLS memory. Recommend starting with item 3 (timing marks) to enable measuring 4–7.

### F7 — Partial-download list inconsistency (low)
`fileSettling.ts` and `libraryCleanup.ts` disagree with `renamePlanner.ts:409` on partial-download extensions (`.opdownload`, `.!qb`, `.!ut`). Consolidate into one exported list per performance doc's "other open issues".

### F8 — Orphan `.loomtv-clean-*.ass` handling (low)
Scanner recognizes these files but nothing writes them; cleanup keeps them. Decide cleanup policy per doc.

### F9 — TV workspace has no lint script (low)
`apps/tv/package.json` lacks `lint`. Add eslint config/script for parity.

### F10 — Mobile Android config verification (info)
Mobile has dedicated verify scripts; ensure CI runs `mobile:verify-android-config` and `mobile:verify-release-config` in release gate (already in mobile-release-gate.yml — confirm).

### F11 — ESLint `no-explicit-any` error across codebase (info)
Enforced; current code has 0 violations. Good. Keep.

### F12 — Secret scanning (pass)
No hardcoded secrets found in source; only test fixtures (`tmdbApiKey`, `fixture-provider-key`). Good.

### F13 — IPC/external URL validation (pass)
