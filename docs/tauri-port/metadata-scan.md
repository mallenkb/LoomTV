# Metadata scan port

`crates/loomtv-core/src/metadata_scan.rs` adds a bounded metadata pass for the shared schema 14 catalog. Its public `enrich_library_metadata` function receives the shared store, the existing `MetadataProviderGateway`, the Owner profile and selection revision captured at scan start, the scan mode, a progress callback, and the scanner's shared cancellation flag.

Quick mode selects incomplete metadata categories and observes the Electron incomplete-refresh cooldown. Full and metadata modes request every unlocked category. The pass uses at most two concurrent item jobs. TMDB, OMDb, and AniList requests go through the existing gateway, so shared `metadataApiKeys`, the legacy `tmdbApiKey` and `omdbApiKey` fallback, offline mode, response limits, host restrictions, TLS policy, retries, and provider concurrency limits remain centralized. A provider failure does not discard usable fields returned by another provider.

The store mutex is released before every provider request. The pass checks cancellation before each request and before each commit. Each item commit reacquires the mutex, requires the same unlocked Owner, checks the selection revision, reloads metadata-category locks, and writes one transaction. A profile change or shutdown cancellation stops the pass before another catalog mutation. Provider failures retain all existing item and episode metadata. The returned summary reports attempted, updated, failed, and skipped item counts and includes up to 32 bounded failure entries; a failed provider pass is not reported as a successful update.

`refresh_incomplete_metadata` applies the quick-mode rules to one media ID and returns whether stored display metadata changed. `streaming_providers` returns the authorized item's sanitized cached provider array when present. When the list is empty, it can request TMDB by the stored TMDB ID and commit a nonempty response. Blank IDs, inaccessible items, offline mode, absent credentials or provider IDs, locked categories, and active retry cooldowns return `false` or the cached array without recording a provider failure. A provider error records the bounded refresh error and returns the cached provider array. Both entry points bind work to the expected active profile and selection revision and apply `Store::can_access_item` before reads and commits.

Primary poster, backdrop, and logo values are filled only when empty. This preserves custom-artwork references and an existing official image selected by the user. Candidate lists retain their current values and append secure provider URLs. Provider IDs are merged, local media paths and episode-file rows are never replaced, and episode enrichment is restricted to season and episode identities that still have local files. User-locked metadata categories are not changed.

This pass covers the providers exposed by `MetadataProviderGateway`. TMDB uses a stored TMDB ID when present; otherwise it requires a normalized title match and prefers a matching release year. OMDb tries a stored IMDb ID, then title and year, then title alone. AniList tries a stored MAL ID before an exact normalized title or alias match. A TMDB result supplies the general movie or series fields. OMDb fills gaps and adds its ratings. AniList takes precedence for anime core fields, artwork, and structured cast.

TMDB supplies core fields, cast, official artwork, ratings, streaming providers, season labels, and metadata for up to 15 local seasons. TVmaze, TVDB, Jikan, Fanart.tv, OpenSubtitles downloads, artwork caching, locale-specific streaming-provider preference, OMDb season episodes, and nonlocal TMDB season extras remain outside this module. An item with more than 64 local seasons or 5,000 local episode identities is left out of the pass. Quick and full handlers can run it after filesystem reconciliation. Metadata mode can run it directly against the current catalog. The handler must return a new library projection after the pass. Wiring and runtime acceptance remain open.

No provider request, application launch, real-library read, or runtime check was performed while adding this module.
