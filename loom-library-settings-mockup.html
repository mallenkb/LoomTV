Analysis

One library model, applied nine times

Plex, Jellyfin and Emby all use the same shape — a library is a type, a name, and one or more folders — and the same setup loop. Loom has the pieces but spreads them across nine pages. The mockup above unifies them.

Plex / Jellyfin pattern

Type, name, folders

Setup wizard and Settings share one Add Library dialog: pick a content type, name it, attach folders. Several folders merge into one library. Mixed-type folders are discouraged in favour of typed libraries.

Loom today

Nine pages, nine empty states

Movies, TV, Anime, Photos, Music, Audiobooks, Books, Comics and Others each onboard separately. Settings shows Movies, TV, Anime and Others only — Music, Books, Comics and Audiobooks have no Settings entry at all.

Sidebar today

Fourteen flat entries

Every library, live source, add-on and custom group pins itself to one icon-only rail with no sections, no counts and no overflow. New kinds only make it longer.

Proposal

Wizard, table, grouped rail

One Add Library flow everywhere, one Libraries table for all nine kinds, and a rail with sections, per-library visibility and a More overflow. Try Fresh install, then Grouped vs Today.

Five changes, in order

  1. Add Library wizard (type → folders → review). Same flow in first-run onboarding and behind Settings → New library. Multi-select types so a starter set is three steps, not nine pages.
  2. One Libraries table. All nine kinds plus custom groups in a single list with folder counts, item counts, status and per-row actions. This fixes “I can’t see the rest”.
  3. Visibility is a setting, not a side effect. Per-library eye toggle plus Hide-empty master switch. Empty libraries stay out of the rail until they have content.
  4. Grouped rail with More overflow. Watch / Listen & Read / Personal / System sections, collapsible, with counts. Rare destinations (extra live sources, add-ons, custom groups) collapse into More.
  5. Folders stay multi-path with inline health. Several folders per library, NAS and permission states on the row, per-library scan — the same health model Settings already has, extended to all kinds.
